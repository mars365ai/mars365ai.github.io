## Brand & Style

This design system delivers an institutional-grade aesthetic engineered for executive enterprise buyers, technical architects, and research leads. The emotional resonance is grounded in mathematical precision, unyielding system stability, and quiet authority. Visual clutter is methodically stripped away to amplify computational velocity, technical rigor, and deep capital trust.

The design movement synthesizes **Minimalist Technical Precision** with **Atmospheric Layering**:
- **Razor Sharp Structure**: Micro-structural lines, systematic grids, and deliberate rhythm derived from elite developer platforms and high-throughput infrastructure suites.
- **Controlled Atmospheric Luminance**: Deep obsidian spatial voids punctuated by focused, optical light fields and radiant refraction effects.
- **Executive Restraint**: Every visual cue must signify purpose; decorative ornaments are replaced with functional metadata, monospaced computational tags, and precise volumetric framing.

## Colors

The palette establishes an ultra-deep tonal foundation that allows luminous spectral accents to convey operational status, systemic intelligence, and interactive focus.

### Surface Architecture
- **Canvas Base (`#080C17`)**: Deep Midnight canvas anchor absorbing peripheral light.
- **Obsidian Sub-surface (`#0B1120`)**: Recessed canvas segments, data tables, and peripheral rails.
- **Elevated Slate Surface (`#111827`)**: Elevated containers, interactive cards, and modal sheets utilizing 60% to 80% opacity paired with back-filter blur.

### Spectral Accents
- **Electric Cobalt (`#3B82F6` / `#527BFF`)**: Primary action driver, high-signal interactive states, and core system telemetry.
- **Hyper Violet (`#8B5CF6`)**: Secondary systemic depth, neural infrastructure metrics, and gradient mesh anchors.
- **Cyber Cyan (`#06B6D4` / `#38BDF8`)**: Diagnostic precision markers, live streaming status, and micro-metrics highlights.

### Typography & Linework
- **Text Primary (`#F8FAFC`)**: High-contrast, optical white ensuring absolute clarity.
- **Text Secondary (`#94A3B8`)**: Mid-tier metadata, interface labels, and supporting architectural copy.
- **Text Muted (`#64748B`)**: De-emphasized structural hints, inactive timestamps, and axis lines.
- **Sub-surface Line (`rgba(255, 255, 255, 0.08)`)**: 1px structural boundaries defining all containment planes.

## Typography

The typographic system leverages a rigorous tri-font configuration balancing architectural presence, sustained reading comfort, and raw machine precision.

- **Primary Display (`Geist`)**: Deployed for massive headlines and navigational focal points. Built with tight tracking, low organic variation, and strict vertical metrics that project institutional confidence.
- **Body & Prose (`Inter`)**: Engineered for complex technical exposition, high density specifications, and multi-paragraph enterprise documentation. Maintains uniform readability across all device densities.
- **Technical Monospace (`JetBrains Mono`)**: Reserved exclusively for telemetry metrics, versioning nodes, system states, key-value data displays, and high-precision status tags. Set with positive letter-spacing (`0.06em`) in micro applications to maximize character separation at 11px.

## Layout & Spacing

The spatial model enforces an uncompromising mathematical rhythm driven by an 8pt base grid with a 4pt micro-subdivision.

### Grid & Breakpoints
- **Desktop (1280px - 1440px max-width)**: 12-column fluid grid, `1.5rem` (24px) gutters, and a minimum outer margin of `3rem` (48px).
- **Tablet (768px - 1024px)**: 8-column layout, `1.5rem` gutters, and `2rem` outer margin.
- **Mobile (< 768px)**: 4-column layout, `1rem` (16px) gutters, and `1.25rem` (20px) outer edge containment.

### Spatial Discipline
Whitespace is applied generously across macro sections to signal category dominance and clarity of thought, while micro-spacing within cards and data tables remains dense, scannable, and compact. Section breaks strictly follow multiples of `4rem` (64px) up to `8rem` (128px) on desktop viewpoints.

## Elevation & Depth

Depth is defined by luminous optical physical properties rather than traditional drop shadows: translucence, refractive edge lighting, and localized atmospheric glow fields.

### Surface Tiers
- **Tier 0 (Infinite Ground)**: `#080C17` flat, absorbs all light.
- **Tier 1 (Plate Substrate)**: `#0B1120` bordered by `1px solid rgba(255, 255, 255, 0.05)`.
- **Tier 2 (Glassmorphic Float)**: `rgba(17, 24, 39, 0.70)` combined with `backdrop-filter: blur(16px)` and perimeter line `1px solid rgba(255, 255, 255, 0.08)`.
- **Tier 3 (Interactive Overlays & Modals)**: `rgba(17, 24, 39, 0.90)` backed by `backdrop-filter: blur(24px)`, topped with an inner linear highlight: `box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.12)`.

### Lighting & Shadow Dynamics
- **Atmospheric Fields**: High-radius radial glows positioned behind primary structural zones: `radial-gradient(ellipse at top, rgba(59, 130, 246, 0.15), transparent 70%)`.
- **Contact Elevation**: Interactive elements apply an ultra-subtle directional lift: `0 8px 32px -4px rgba(0, 0, 0, 0.5)`.
- **Edge Illumination**: Borders on active or hovered surfaces transition to linear directional highlights using primary cobalt and violet spectrum values at low opacity (`rgba(59, 130, 246, 0.4)`).

## Shapes

The geometric signature is disciplined, structured, and modern. Sharp corners are softened precisely to eliminate visual friction without introducing playful or casual curves.

- **Base Radius (`0.25rem` / 4px)**: Standard for micro-components, inline code tags, buttons, badges, and input elements.
- **Container Radius (`rounded-lg` / `0.5rem` / 8px)**: Applied to cards, panels, modules, and dropdown viewports.
- **Modal Radius (`rounded-xl` / `0.75rem` / 12px)**: Structural maximum, reserved exclusively for floating enterprise overlays, dynamic dialogs, and mega-menus.
- **Pill Exception**: Full circular geometry (`9999px`) is reserved exclusively for live system status indicators and monospaced diagnostic telemetry chips.

## Components

### Buttons
- **Primary Action**: Gradient wash from `#3B82F6` to `#527BFF`, crisp white text (`#F8FAFC`), structural inset highlight `inset 0 1px 0 rgba(255,255,255,0.2)`, zero external blur. Hover triggers a smooth opacity bloom and fine blue edge glow.
- **Secondary (Glass)**: `rgba(255,255,255,0.03)` base with `1px solid rgba(255,255,255,0.08)`. Hover transitions to `rgba(255,255,255,0.07)` and `border-color: rgba(255,255,255,0.20)`.
- **Tertiary / Ghost**: Transparent base, text `#94A3B8`. Hover transitions text to `#F8FAFC` with subtle letter spacing tension.

### Micro-Monospace Chips & Badges
- Encased in `JetBrains Mono` at `11px`, uppercase, `0.06em` letter spacing.
- Background: `rgba(59, 130, 246, 0.08)`.
- Perimeter: `1px solid rgba(59, 130, 246, 0.25)`.
- Content: Accompanied by a 6px pulsating live indicator dot (`#06B6D4` or `#3B82F6`).

### Input Fields & Controls
- Base background `#0B1120`, border `1px solid rgba(255,255,255,0.08)`.
- Focus state: Border instantly locks to `#3B82F6`, paired with an ambient ring: `0 0 0 1px #3B82F6, 0 0 16px -2px rgba(59, 130, 246, 0.3)`.
- Placeholder text in `#64748B`. Font family strictly set to `Inter`.

### Checkboxes & Radios
- Size: `16px x 16px` with subtle `2px` corner rounding for checkboxes, circular for radios.
- Inactive: Border `1px solid rgba(255, 255, 255, 0.15)`, background `rgba(255, 255, 255, 0.02)`.
- Active: Background `#3B82F6`, check icon crisp `#F8FAFC` rendered at 1.5px stroke width.

### Content Cards
- Constructed with `rgba(17, 24, 39, 0.65)`, `1px solid rgba(255, 255, 255, 0.08)`, and `backdrop-filter: blur(12px)`.
- Top boundary features a microscopic gradient highlight line (`rgba(255, 255, 255, 0.12)` fading to transparent at the edges).
- Interactive card variants deploy localized cursor-following radial highlight effects across the border perimeter on mousemove.

### Telemetry / Metric Callouts
- High-visibility structural modules featuring headline-level statistics.
- Value set in `Geist` or `JetBrains Mono`, labeled with an uppercase muted sub-text tag (`#64748B`).
- Sub-grid division lines utilize `rgba(255,255,255,0.04)` to structure multi-metric rows.
